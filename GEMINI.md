# Coding Guidelines

- Always use descriptive, self-explanatory variable names instead of one-letter variables.
- Before touching `backend/`, read `backend/AGENTS.md` and follow its file structure and patterns.
- After every change in the codebase, always run `yarn test-server` from the root directory, and run `yarn check-all` (or `yarn build`, `yarn lint`, `yarn format:check`, and `yarn test`) from the `frontend/` directory.
